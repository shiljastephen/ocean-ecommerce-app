# 🌊 Ocean – Full Stack Ecommerce Application

Ocean is a full-stack ecommerce shopping platform built using Django and React.  
Users can browse products, add items to cart, and place orders.

---

## 🚀 Features

- User Registration & Login  
- Product Listing  
- Product Detail Page  
- Add to Cart  
- Order Management  
- REST API Integration  

---

## 🛠 Tech Stack

**Backend:** Django, Django REST Framework  
**Frontend:** React (Vite)  
**Database:** MySQL  

---

## 📁 Project Structure

backend → Django project  
frontend → React application
